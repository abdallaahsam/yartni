# منصة ياريتني (Yareetni) 🌟

> **"لو رجع بيا الزمن.. إيه النصيحة اللي كنت تحب تعرفها؟"**
> 
> منصة تواصل اجتماعي وحكمة حياتية تهدف لتبادل التجارب والنصائح الواقعية بين الأجيال؛ ليستفيد منها من يمر بنفس المرحلة العمرية اليوم ويتجنب الأخطاء المكلفة.

---

## 🚀 المميزات المعمارية والتقنية

1. **روابط مهيئة لمحركات البحث (SEO-Friendly Slugs)**:
   - روابط النصائح قابلة للمشاركة بصيغة: `/advice/:id/:slug`.
2. **فصل هيكل النصيحة إلى 3 أركان جوهرية**:
   - `headline`: عنوان النصيحة وفكرتها المركزة.
   - `story`: القصة الواقعية والسياق الذي أدى لهذه النتيجة.
   - `lesson`: العبرة العملية المركزة ("لو رجع بيا الزمن هعمل...").
3. **محرك بحث فائق السرعة يدعم العربية (SQLite FTS5)**:
   - جدول بحث افتراضي مع فهارس ومعالجة الصرف العربي والسوابق (مثل "ال" التعريف).
4. **خوارزميات فرز متقدمة للـ Feed**:
   - **الصاعدة 🔥 (Trending)**: خوارزمية جاذبية تناقصية تحسب التفاعل بالنسبة لحداثة المنشور.
   - **الأكثر تأثيراً (Top)**: حسب مرات "أثرت فيّ".
   - **الأحدث (Latest)**: حسب وقت النشر.
5. **فلترة سريعة بالأعمار والتصنيفات**:
   - شريط أعمار سريع: `جميع الأعمار، 18، 20، 22، 25، 30، 35، 40+`.
   - 7 مجالات حياتية رئيسية (تعليم، عمل، مال، علاقات، صحة، تطوير ذات، أسرة).
6. **الملف الشخصي ونظام الأوسمة (Gamification Badges)**:
   - مسار مخصص لكل مستخدم: `/u/:username`.
   - أوسمة ذكية تُحسب ديناميكياً: *خطوة أولى، مساهم نشط، أثر ذهبي، حكيم العشرينات، خبير الحياة*.
7. **التفاعل الاجتماعي والمفضلة**:
   - تأييد "أثرت فيّ" مع تأثير احتفالي (Confetti).
   - حفظ النصائح في المفضلة الخاصة `/saved`.
   - قسم كامل للمناقشات وتبادل التجارب المكملة.
   - نظام الإبلاغ عن المحتوى غير اللائق (`reports`).
8. **المظهر والوضع الداكن (Dark / Light Mode)**:
   - دعم الوضعين المضيء والداكن مع حفظ التفضيل محلياً وتصميم عربي أصيل (RTL).

## 🛠️ كيفية التشغيل محلياً (Quick Start)

### 1. تشغيل الخادم الخلفي (Backend)
```bash
cd server
npm start
```
> الخادم سيعمل على: `http://localhost:5000`

### 2. تشغيل واجهة المستخدم (Frontend)
في نافذة موجه أوامر جديدة:
```bash
cd client
npm run dev
```
> افتح المتصفح على: `http://localhost:5173`
