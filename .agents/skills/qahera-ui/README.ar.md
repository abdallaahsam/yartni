# مهارة نظام تصميم القاهرة (`qahera-ui`)

> محرك نظام التصميم الذكي والسيادي لواجهات المستخدم من **الوكالة (Alwkala)**.

$$\mathbf{\text{Qahera UI Kit}} = \mathbf{\text{نظام التصميم}} + \mathbf{\text{سجل المكونات}} + \mathbf{\text{طبقة قرارات الذكاء الاصطناعي}}$$

---

## نظرة عامة

مهارة **`qahera-ui`** هي طبقة اتخاذ القرار الرسمية (AI Decision Layer) الخاصة بـ **نظام تصميم القاهرة (Qahera UI Kit)**. تُدير المهارة عمليات تأليف المكونات، وتركيب الشاشات المتكاملة، وفحص جودة المعايير الـ 15، وتوليد الأكواد لـ 6 مستهدفات تصيير مختلفة انطلاقاً من عقود ووصفات الـ YAML الأصلية (`contracts/` و `recipes/`).

### التوافق الكامل مع 6 مستهدفات تصيير متزامنة
1. **HTML الأصيل (Native)**: كود HTML5 دلالي نقي مع خصائص CSS المخصصة وتفاعلات Alpine.js خفيفة.
2. **HTML مع Tailwind**: متوافق مع Tailwind CSS v3/v4 عبر حزمة `@alwkala/qahera-tailwind-preset`.
3. **React 19 (Server Components)**: مكونات خادم نقية تحافظ على بصمة 0kb جافاسكربت على العميل.
4. **PHP (Plates / Native)**: تصيير مباشر في بيئات PHP الخادومية (`$qhr->render(...)`).
5. **HTMX**: عناصر تفاعلية مدفوعة بالـ Hypermedia (`hx-get`, `hx-swap`).
6. **مكونات الويب (Web Components)**: عناصر مخصصة مستقلة تماماً (`<qhr-...>`).

## المعايير الـ 15 الصارمة (AGENTS.md)

1. **الـ YAML هو المرجع المطلق**: العقود والوصفات والتوكنز بصيغة YAML هي مصدر الحقيقة الوحيد.
2. **التوكنز تسبق التنسيق**: حظر كتابة قيم الألوان بالهيكس أو البكسل المباشر؛ الاعتماد كلياً على `--qhr-*`.
3. **العقود تسبق التنفيذ**: لا يُبنى أي مكون دون توثيق عقده أولاً في `contracts/`.
4. **دعم العربية بنية تحتية وليس ثيم**: استخدام الخصائص المنطقية 100% (`margin-inline-start`, `padding-inline-end`).
5. **انضباط الخطوط العربية**: خط **الإسكندرية (Alexandria)** للعناوين والهوية، وخط **القاهرة (Cairo)** لنصوص الواجهات. حظر خط Amiri تماماً في الواجهات.
6. **تطابق المخرجات بلا انحراف**: تطابق كامل لأسماء الخصائص والـ variants عبر الـ 6 Renderers.
7. **الأيقونات معمارية وليست إيموجي (`QAHERA-VISUAL-001`)**: حظر الإيموجي نهائياً؛ الاعتماد على كتالوج الأيقونات الرسمي (`icons/registry.yaml`).
8. **الاعتماد الصارم على الذات (`QAHERA-COMP-001`)**: منع ابتكار فئات CSS عشوائية من الرأس؛ التركيب يتم حصراً من الـ 42 وصفة والـ 20 نمطاً.
9. **سلامة تفاعلات ألبين (`QAHERA-ALPINE-001`)**: مفاتيح فريدة للـ templates، منع المنطق البرمجي داخل السمات، ومنع العناصر التفاعلية داخل الروابط.
10. **الطابع المعماري المصري (`QAHERA-THEME-001`)**: ثيمات تعبر عن أحياء مصرية (مصر الجديدة، وسط البلد، القاهرة الجديدة، المعادي، النوبة).
11. **ختم النقد السباعي الإلزامي**: تقييم كل كود قبل إصداره بـ: `/* Pre-emit critique: P5 H5 E5 S5 R5 V5 D5 */`.
12. **الهيكلية المعيارية للملفات**: ملف CSS مستقل لكل مكون في `renderers/html/native/components/*.css`.
13. **بروتوكول الذكاء التراكمي**: قراءة الحد الأدنى من السياق (Level 0 Index $\to$ Level 1 Metadata $\to$ Level 2 Recipe).
14. **طبقة القرارات الذكية (CDL)**: حسم المعايير المعمارية قبل التوليد.
15. **ملكية الكود المصدرية**: يمتلك المطور الكود بالكامل في مشروعه دون قيود runtime خارجية.

## الفحص والتحقق الآلي

لتشغيل جناح الفحص الحتمي الشامل في المستودع:
```bash
node bin/qahera.js test
```
يقوم بفحص صحة المخططات، ونسب تباين الألوان للوصول الشامل (WCAG 2.1 AA)، وميزانية الأداء، وتوافق الـ RTL بنسبة 100%.
